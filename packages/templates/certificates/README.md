# Certificates — Template Sertifikat

Template sertifikat kelulusan / penghargaan THS-THM (Pedoman No 3/2004).
Format: landscape A4 (pendadaran/pelatihan), portrait A4 (Lampiran 2-6).

## File

- `preview_sertifikat_pendadaran_ths_thm.jsx` — Sertifikat Pendadaran
- `preview_sertifikat_pelatihan_ths_thm.jsx` — Sertifikat Pelatihan
- `sertifikat_tingkatan_a4_portrait_template.jsx` — Sertifikat Tingkatan (Lampiran 3, penerbit Nasional)
- `sertifikat_pelatih_a4_portrait_template.jsx` — Sertifikat Pelatih (Lampiran 4, ttd Dewan Pendiri + Koordinator Nasional)
- `sertifikat_wasit_dan_juri_a4_portrait_template.jsx` — Sertifikat Wasit & Juri (Lampiran 5)
- `sertifikat_penguji_a4_portrait_template.jsx` — Sertifikat Penguji (Lampiran 6)

## Variabel Template

- `recipientName` — Nama penerima
- `title` — Judul sertifikat
- `description` — Deskripsi penghargaan
- `date` — Tanggal penerbitan
- `signatoryName` — Nama penandatangan
- `signatoryRole` — Jabatan penandatangan
