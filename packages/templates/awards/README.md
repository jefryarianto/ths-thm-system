# Awards — Template Piagam Penghargaan

Template piagam penghargaan THS-THM (Pedoman No 3/2004, Bab VI).
Format: portrait A4.

## File

- `piagam_prestasi_a_4_landscape_template.jsx` — Piagam Prestasi generik
- `piagam_seroja_a4_landscape_template.jsx` — Piagam Seroja (lambang perjuangan, penerbit Distrik/Komisariat)
- `piagam_melati_a4_landscape_template.jsx` — Piagam Melati T1–T5 (lambang kesetiaan, masa aktif 5/10/20/30/40 th)
- `piagam_mawar_a4_landscape_template.jsx` — Piagam Mawar (kesucian & kemuliaan, ttd Dewan Pendiri + Koordinator Nasional + Moderator Nasional)

## Variabel Template

- `recipientName` — Nama penerima
- `awardTitle` — Judul penghargaan
- `category` — Kategori (contoh: Akademik, Non-Akademik)
- `reason` — Alasan penghargaan
- `date` — Tanggal
- `signatoryName` — Nama penandatangan
- `signatoryRole` — Jabatan penandatangan
