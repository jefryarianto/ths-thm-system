# Keyboard Shortcuts - Members Page

## Navigation

| Key | Action |
|-----|--------|
| `↑` / `↓` | Navigate table rows |
| `Enter` | Open selected member detail |
| `Home` | Go to first row |
| `End` | Go to last row |
| `Esc` | Clear selection |

## Search & Filters

| Key | Action |
|-----|--------|
| `/` | Focus search bar |
| `Esc` | Clear search / close dropdowns |
| `Tab` | Next field |
| `Shift + Tab` | Previous field |

## Selection

| Key | Action |
|-----|--------|
| `Space` | Toggle row selection |
| `Ctrl + A` | Select all on page |
| `Delete` | Delete selected (with confirmation) |

## Table

| Key | Action |
|-----|--------|
| `↑` / `↓` | Sort column (click to toggle) |
| `Space` | Toggle checkbox |

## Tips

- **Arrow keys** only work when table is focused
- Press `Esc` to exit table focus
- Sort arrows appear on column hover
- Active row is highlighted with blue background

---

## Accessibility

All interactive elements:
- Have `aria-label` attributes
- Are keyboard navigable
- Show focus indicators
- Support screen readers
